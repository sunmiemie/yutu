# VAD 音频切割使用说明

脚本：[vad_audio_splitter.py](vad_audio_splitter.py)。输入为 PCM WAV 音频，输出为 WAV 片段、JSON 清单及可供 Excel 打开的 UTF-8 BOM CSV。

## 安装与查看帮助

在运行脚本的同一个 Python 环境中安装依赖：

```bash
python -m pip install silero-vad
python vad_audio_splitter.py --help
```

查看帮助不需要安装 Silero/PyTorch；实际语音检测需要依赖可用。脚本支持 Python 3.9 及以上版本，依赖的 Python 版本要求请以所安装的 silero-vad 版本为准。

## 切分一个音频

```bash
python vad_audio_splitter.py --audio "录音/sample.wav"
```

默认输出到 `录音/vad_output/sample/`，文件前缀取自输入音频文件名。也可以指定目录和英文前缀：

```bash
python vad_audio_splitter.py --audio "录音/sample.wav" --output-dir "结果/sample-第一次" --output-prefix Sample
```

得到 `Sample-001.wav` 等片段，以及 `Sample_vad_segments.json` 和 `Sample_vad_segments.csv`。文件名前缀中的非 ASCII 字母、数字、下划线和连字符会转换为连字符；转换后为空则使用 `output`。中文原文件夹名保持不变。

## 批量处理文件夹

```bash
python vad_audio_splitter.py --folder "录音" --threshold 0.6 --extra-pad-sec 0.3
python vad_audio_splitter.py --folder "录音" --output-dir "批量结果"
```

处理指定文件夹第一层的 `.wav` 文件（扩展名不区分大小写），不递归处理子文件夹。默认保存到 `录音/vad_output/音频文件名/`；指定输出目录时，仍会为每个输入音频创建单独的子目录。批量模式不能指定统一的 `--output-prefix`。

不带参数运行时，仍会提示输入文件夹地址：

```bash
python vad_audio_splitter.py
```

无需修改源代码顶部的路径。带参数运行必须明确指定 `--audio` 或 `--folder`。

## 参数与切割规则

完整参数见 `--help` 和 [VAD 切割参数说明](VAD切割参数说明.md)。默认规则：

- 检测采样率 16000 Hz，阈值 0.5。
- 最短语音时长 500 ms，切分所需最短静音 500 ms。
- VAD 最长语音段 30 秒；后处理合并和补边可能使导出段更长。
- 默认不合并相近或较短片段。
- 每段前后额外保留 0.5 秒，相邻片段可重复保留这部分音频。
- 最终不足 0.5 秒的片段不导出。

检测时间戳以采样位置换算，计算过程保留精度；导出 WAV 使用原始采样率、声道数和采样宽度。JSON 记录片段边界与配置，控制台和 CSV 以毫秒精度显示时长。

## 结果保护与错误处理

同一输出目录中若已有相同前缀的 WAV 片段或清单，脚本会停止并提示更换目录或前缀，避免覆盖和新旧结果混用。临时导出失败不会留下本次未完成的清单和片段；不删除已有文件。

常见原因包括输入文件不存在、WAV 格式不受支持、音频数据截断、依赖缺失、参数为负数/NaN/无穷大或输出文件被占用。命令行会报告错误并返回非零状态码。没有检测到语音时会生成空清单，不生成 WAV 片段。

## 离线回归测试

在仓库根目录运行：

```bash
python -m unittest discover -s tests -v
```

测试使用临时合成 PCM WAV 和模拟检测结果，不加载真实模型、不连接网络、不处理仓库内的真实录音。
