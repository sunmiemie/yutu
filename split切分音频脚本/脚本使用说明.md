# VAD 音频切割使用说明

这份说明面向第一次接触这个脚本的用户。

脚本文件位置：  
[vad_audio_splitter.py](D:/Users/Desktop/工作123/语图/12345/vad_audio_splitter.py)

这个脚本的作用是：

- 读取一个 `wav` 音频
- 自动识别人声片段
- 按规则切成多个小音频
- 输出切分后的音频、JSON 清单、CSV 清单

## 一、使用前要确认的事

1. 输入文件必须是 `.wav`
2. 电脑里要有可用的 Python
3. 运行脚本的 Python 环境里要安装 `silero-vad`

## 二、如何安装 `silero-vad`

第一次在新电脑或新 Python 环境里使用时，需要先安装 `silero-vad`。

### 方法 1：直接安装

打开终端，运行：

```bash
python -m pip install silero-vad
```

安装完成后，可以检查是否成功：

```bash
python -c "import silero_vad; print('silero-vad 安装成功')"
```

如果终端输出：

```text
silero-vad 安装成功
```

说明安装完成。

### 方法 2：给指定 Python 安装

如果你的编辑器不是用系统默认 Python，而是用指定解释器，就要给那个解释器单独安装。

例如：

```bash
C:\dev\python\python.exe -m pip install silero-vad
```

意思是：把 `silero-vad` 安装到 `C:\dev\python\python.exe` 这个 Python 环境里。

### 常见安装问题

#### 1. 报错 `No module named pip`

说明当前 Python 环境里没有 `pip`。  
这时建议换一个正常可用的 Python 解释器，再安装。

#### 2. 报错 `No module named silero_vad`

说明：

- 还没有安装 `silero-vad`
- 或者装在了别的 Python 环境里

这时要确认两件事：

- 运行脚本用的是哪个 Python
- 安装 `silero-vad` 用的是哪个 Python

这两个必须一致。

## 三、最简单的运行方式

这个脚本已经支持“直接改代码顶部路径，然后点运行”。

打开文件：  
[vad_audio_splitter.py](D:/Users/Desktop/工作123/语图/12345/vad_audio_splitter.py)

在最上面找到这 3 行：

```python
DEFAULT_AUDIO_PATH = r"d:\Users\Desktop\工作123\语图\佐藤(男)「電話に出る／出ない」.wav"
DEFAULT_OUTPUT_DIR = r"d:\Users\Desktop\工作123\语图\12345\vad_output"
DEFAULT_OUTPUT_PREFIX = "Japan2"
```

它们分别表示：

- `DEFAULT_AUDIO_PATH`  
  输入音频路径，也就是要切的原始 `wav`
- `DEFAULT_OUTPUT_DIR`  
  输出目录，也就是切好的音频保存到哪里
- `DEFAULT_OUTPUT_PREFIX`  
  输出文件名前缀，例如会生成 `Japan2-001.wav`

改完以后，直接运行这个脚本即可。

## 四、新用户第一次运行的完整步骤

1. 用编辑器打开 [vad_audio_splitter.py](D:/Users/Desktop/工作123/语图/12345/vad_audio_splitter.py)

## 五、以后更换文件地址怎么做

以后要切别的音频时，只需要改顶部这 3 项。

### 1. 更换输入音频

把：

```python
DEFAULT_AUDIO_PATH = r"d:\Users\Desktop\工作123\语图\佐藤(男)「電話に出る／出ない」.wav"
```

改成新的 `wav` 路径，例如：

```python
DEFAULT_AUDIO_PATH = r"d:\Users\Desktop\工作123\语图\新的音频.wav"
```

### 2. 更换输出目录

把：

```python
DEFAULT_OUTPUT_DIR = r"d:\Users\Desktop\工作123\语图\12345\vad_output"
```

改成新的输出目录，例如：

```python
DEFAULT_OUTPUT_DIR = r"d:\Users\Desktop\工作123\语图\12345\vad_output_new"
```

建议每次换一个新目录，避免和旧结果冲突。

### 3. 更换输出文件名前缀

把：

```python
DEFAULT_OUTPUT_PREFIX = "Japan2"
```

改成你想要的前缀，例如：

```python
DEFAULT_OUTPUT_PREFIX = "Tokyo"
```

这样输出文件会变成：

- `Tokyo-001.wav`
- `Tokyo-002.wav`

## 六、推荐的更换逻辑

每次处理一个新音频时，建议按这个顺序改：

1. 先改 `DEFAULT_AUDIO_PATH`
2. 再改 `DEFAULT_OUTPUT_DIR`
3. 最后改 `DEFAULT_OUTPUT_PREFIX`

推荐示例：

```python
DEFAULT_AUDIO_PATH = r"d:\Users\Desktop\工作123\语图\test01.wav"
DEFAULT_OUTPUT_DIR = r"d:\Users\Desktop\工作123\语图\12345\vad_output_test01"
DEFAULT_OUTPUT_PREFIX = "Test01"
```

## 七、输出结果怎么看

运行成功后，会得到三类结果。

### 1. 切好的音频

例如：

- `Japan2-001.wav`
- `Japan2-002.wav`

这是最终要使用的小音频。

### 2. JSON 清单

例如：

- `Japan2_vad_segments.json`

作用：

- 记录每一段的起止时间
- 记录本次运行时使用的切割参数

### 3. CSV 清单

例如：

- `Japan2_vad_segments.csv`

作用：

- 可以直接用 Excel 打开
- 方便查看每一段音频对应的时间区间

## 八、当前切割逻辑是什么

当前脚本的规则大意是：

- 连续静音达到 `500ms` 就切开
- 最短有效语音片段按 `500ms` 处理
- 不再因为“片段太短”自动并回去
- 每段前后额外保留 `500ms` 静音
- 相邻片段允许重复这部分静音

## 九、常见问题

### 1. 运行时报 `No module named silero_vad`

说明当前编辑器选的 Python 环境里没装依赖，不是脚本坏了。

### 2. 运行时报 `Permission denied`

说明输出文件正在被占用。常见处理方式：

- 关闭音频播放器
- 关闭正在预览该音频的窗口
- 换一个新的输出目录

### 3. 明明中间停顿很长，却没有切开

原因通常是：

- 模型没有把那一段完整识别成“连续静音”
- 听起来像停顿，但里面还有尾音、呼吸声、底噪
